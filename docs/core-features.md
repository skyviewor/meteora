# Aerolytica 核心亮点

Aerolytica 是面向气象与地球科学研究的 AI Agent IDE。它不只是回答问题，而是围绕一个真实项目目录，持续完成数据获取、分析实验、资料整理、成果记录和论文交付。

## 1. 气象数据的一站式工作流

Aerolytica 内置面向专业气象数据源的查询与下载能力，支持 ERA5、MERRA-2、CAMS、GFS、GEFS、ECMWF IFS/AIFS、JRA、NCEP 再分析，以及多种地面观测、卫星和降水产品。Agent 能理解时间、区域、层次和变量要求，检查请求参数，并对 NetCDF、GRIB2、CSV 等结果继续开展检查、裁剪、统计和绘图。

## 2. 以项目为边界的可控 Agent

用户启动 `aero chat` 时所在的目录就是项目根目录。数据、脚本、图片、计划、文献和会话均围绕当前项目组织，不会沿用其他目录的工作状态。TUI 提供流式交互、会话续接、上下文压缩、权限确认和后台子 Agent，适合持续时间较长的科研任务。

## 3. 实验、检查点与安全恢复

“实验”功能为不同研究尝试创建独立目录和上下文，集中保存脚本、图片、计划与报告，避免多个方案的中间产物互相混杂。主流程和每个实验拥有各自的检查点历史，可查看差异、保存阶段状态并恢复；恢复前自动建立保护记录，降低误覆盖风险。实验完成后，Agent 会总结结果并形成报告。

## 4. 从资料查询到研究结论沉淀

Aerolytica 同时支持互联网搜索、学术文献检索、PDF 下载与阅读。研究过程中形成的重要判断可以加入项目备忘录，记录结论、依据、限制条件和来源实验。后续撰写实验报告、总结或论文时，Agent 可以直接复用这些经过确认的研究资产，而不必重新翻找聊天记录。

## 5. 面向论文的独立工作流

论文正文固定为 `paper/main.md`，与项目代码检查点相互独立。用户可以保存论文版本、查看逐行变化并安全回滚。正文可通过统一命令导出为 LaTeX、Word 或 PDF：

```text
/paper export latex
/paper export word
/paper export pdf
```

Word 与 PDF 会带入正文引用的本地图片；LaTeX 保留可维护的图片引用。导出依赖由统一的 `aero-agent` 运行环境管理，并在 TUI 中显示安装与转换状态。

## 6. 多模型与多模态能力

项目支持 DeepSeek、阿里云百炼、Kimi、OpenAI-compatible 等模型服务，也允许用户配置自己的兼容接口。视觉模型可分析科研图件；生成的图片优先直接嵌入对话，同时允许按用户要求用系统工具打开图片或 PDF。API Key 独立保存在用户级密钥配置中，不写入项目文件。

## 7. 可扩展的科研工具体系

数据适配器、Agent 工具、Skills 和运行时依赖彼此分层。成熟领域工具优先于临时脚本，CDO、NCO、ecCodes、Pandoc 等命令行能力由统一环境安装和验证。新数据源、新分析方法和新交付格式可以沿现有接口继续扩展。

## 一句话概括

**Aerolytica 将气象数据、可控实验、研究记忆和论文交付放进同一个可恢复、可持续的 AI 科研工作流。**
