# 风场垂直剖面图中的矢量绘制技巧

## 1. 问题背景

在绘制风场垂直剖面图时，通常会使用：

- 沿剖面方向的水平风分量；
- 垂直速度 \(w\)；

共同组成剖面内的二维风矢量。

假设剖面沿径向方向展开，则剖面矢量可以写成：

\[
(V_r, w)
\]

其中：

- \(V_r\)：沿剖面方向的水平风速；
- \(w\)：垂直速度。

实际数据中，二者的量级通常相差较大：

- 水平风速常为 \(1\sim20\ \mathrm{m\,s^{-1}}\)；
- 垂直速度常为 \(0.01\sim1\ \mathrm{m\,s^{-1}}\)。

如果直接按照真实数值绘制，箭头会几乎全部呈水平方向，垂直运动结构很难辨认。

---

## 2. 最常用的方法：放大垂直速度

通常的做法是对垂直速度乘以一个人为放大系数：

\[
(V_r, w)
\quad\longrightarrow\quad
(V_r, \alpha w)
\]

其中 \(\alpha\) 是垂直速度放大倍数。

常用取值包括：

- 5 倍；
- 10 倍；
- 20 倍；
- 50 倍。

具体倍数应根据水平风和垂直速度的典型量级确定。

例如：

```python
w_factor = 20
w_plot = w * w_factor
```

然后绘制：

```python
q = ax.quiver(
    distance,
    height,
    vr,
    w_plot,
    scale=250,
)
```

### 图中必须标注放大倍数

因为此时箭头方向已经不是严格意义上的真实气流方向，所以应在图题、图例或图注中明确注明：

```text
Vertical velocity exaggerated by a factor of 20
```

或：

```text
垂直速度放大 20 倍
```

---

## 3. 如何确定垂直速度放大倍数

可以先根据典型量级估算。

假设：

\[
V_r \approx 10\ \mathrm{m\,s^{-1}}
\]

\[
w \approx 0.2\ \mathrm{m\,s^{-1}}
\]

则二者量级比约为：

\[
\frac{10}{0.2}=50
\]

从纯数值尺度看，可以将 \(w\) 放大约 50 倍。

但实际绘图时，不一定需要让二者完全处于同一量级。通常只需要让上升和下沉结构足够清楚。

建议依次尝试：

```python
w_factor = 10
```

```python
w_factor = 20
```

```python
w_factor = 50
```

然后根据图形效果选择。

一般原则是：

> 放大到足以观察垂直运动结构，但不要让箭头显得过度竖直或夸张。

---

## 4. 剖面图本身的垂直夸张

垂直剖面通常存在明显的横纵尺度差异。

例如：

- 水平距离为 500 km；
- 垂直高度为 15 km。

如果严格按照真实空间比例绘制，剖面图会非常扁平。

因此绘图时通常会在视觉上放大垂直方向。其垂直夸张倍数约为：

\[
E=\frac{500}{15}\approx33
\]

也就是说，即使数据本身没有改变，显示出来的剖面已经在视觉上放大了垂直结构。

但是需要注意：

> 坐标轴的纵横比例与风矢量分量的缩放并不是同一个问题。

Matplotlib 中 `quiver` 的箭头方向是否跟随坐标轴缩放，与 `angles`、`scale_units` 等参数有关。

---

## 5. Matplotlib 中 `angles` 的选择

### 5.1 `angles="uv"`

```python
ax.quiver(
    distance,
    height,
    vr,
    w_factor * w,
    angles="uv",
    scale=250,
)
```

此时箭头方向主要按照屏幕坐标解释。

特点：

- 箭头视觉方向较稳定；
- 不严格对应数据坐标中的几何斜率；
- 比较适合气象场中的示意性风矢量。

这是许多业务图和论文图中较常见的方式。

---

### 5.2 `angles="xy"`

```python
ax.quiver(
    distance,
    height,
    vr,
    w_factor * w,
    angles="xy",
    scale_units="xy",
    scale=1,
)
```

此时箭头按照数据坐标中的方向解释。

特点：

- 箭头方向会受到横纵坐标单位和比例影响；
- 更接近数据坐标中的几何方向；
- 如果横轴和纵轴单位不同，需要特别谨慎。

例如：

- 横轴为 km；
- 纵轴为 km；
- 风速分量为 \(\mathrm{m\,s^{-1}}\)。

此时速度分量和坐标轴并不属于同一种物理量，不能简单认为箭头倾角就是气流真实倾角。

---

## 6. 归一化矢量：只显示流向

如果主要目标是观察环流结构，而不强调箭头长度代表的风速大小，可以将每个矢量归一化。

首先定义放大后的矢量模长：

\[
S=\sqrt{V_r^2+(\alpha w)^2}
\]

然后计算归一化分量：

\[
\hat V_r=\frac{V_r}{S}
\]

\[
\hat w=\frac{\alpha w}{S}
\]

示例代码：

```python
import numpy as np

w_factor = 20

speed_plot = np.hypot(vr, w_factor * w)

u_dir = vr / np.where(speed_plot == 0, np.nan, speed_plot)
w_dir = w_factor * w / np.where(speed_plot == 0, np.nan, speed_plot)

ax.quiver(
    distance,
    height,
    u_dir,
    w_dir,
    angles="uv",
    scale=25,
)
```

这种方法的特点是：

- 箭头长度基本一致；
- 更容易观察闭合环流、上升支和下沉支；
- 箭头长度不再表示实际风速；
- 必须在图注中注明矢量已经归一化。

可以注明：

```text
Vectors are normalized; arrow direction indicates airflow structure only.
```

或：

```text
矢量已归一化，箭头仅表示气流方向。
```

---

## 7. 更推荐的表达方式：底图与矢量分工

风场剖面图中，通常不建议让箭头同时承担以下全部信息：

- 风向；
- 水平风速大小；
- 垂直速度大小；
- 上升和下沉区域。

更合理的方式是把不同信息分配给不同图层。

### 推荐组合

- 底图填色：垂直速度 \(w\)；
- 等值线：温度、位温、相对湿度或雷达反射率；
- 风矢量：\((V_r,\alpha w)\)；
- 参考箭头：表示水平风速尺度；
- 图注：说明 \(w\) 的放大倍数。

例如：

```python
import numpy as np
import matplotlib.pyplot as plt

w_factor = 20

fig, ax = plt.subplots(figsize=(12, 5))

cf = ax.contourf(
    distance,
    height,
    w,
    levels=np.arange(-2, 2.1, 0.2),
    extend="both",
)

q = ax.quiver(
    distance[::3],
    height[::2],
    vr[::2, ::3],
    (w_factor * w)[::2, ::3],
    angles="uv",
    scale=250,
    width=0.002,
)

ax.quiverkey(
    q,
    X=0.82,
    Y=1.04,
    U=10,
    label=r"10 m s$^{-1}$ horizontal; $w\times20$",
    labelpos="E",
)

ax.set_xlabel("Distance along cross-section (km)")
ax.set_ylabel("Height (km)")
ax.set_title("Vertical cross-section of airflow")

fig.colorbar(
    cf,
    ax=ax,
    label=r"Vertical velocity $w$ (m s$^{-1}$)",
)

plt.tight_layout()
plt.show()
```

这种设计的优点是：

- 底图直接显示上升和下沉强度；
- 箭头显示剖面环流方向；
- 水平风强度仍可通过箭头长度大致判断；
- 不需要依赖箭头精确表达很小的垂直速度。

---

## 8. 沿任意剖面方向投影水平风

如果剖面不是严格沿东西方向或南北方向，就不应直接使用原始的 \(u\) 或 \(v\) 分量。

假设：

- \(u\)：东西向风分量，向东为正；
- \(v\)：南北向风分量，向北为正；
- \(\theta\)：剖面方向相对于正东方向的夹角。

则沿剖面方向的风分量为：

\[
V_r=u\cos\theta+v\sin\theta
\]

垂直剖面中的矢量应使用：

\[
(V_r,w)
\]

示例：

```python
import numpy as np

theta_deg = 45.0
theta = np.deg2rad(theta_deg)

vr = u * np.cos(theta) + v * np.sin(theta)
```

如果还需要计算垂直于剖面的水平风分量，可以使用：

\[
V_n=-u\sin\theta+v\cos\theta
\]

代码：

```python
vn = -u * np.sin(theta) + v * np.cos(theta)
```

其中：

- \(V_r\)：沿剖面方向；
- \(V_n\)：垂直于剖面方向。

绘制剖面内环流时，应使用 \(V_r\) 和 \(w\)。

---

## 9. 如果剖面是径向剖面

如果剖面从某个中心点沿方位角切出，可以根据方位角计算径向风。

若方位角 \(\phi\) 按气象习惯定义：

- 正北为 \(0^\circ\)；
- 正东为 \(90^\circ\)；
- 顺时针增加；

则径向方向单位向量为：

\[
(\sin\phi,\cos\phi)
\]

因此沿径向的风分量可写为：

\[
V_r=u\sin\phi+v\cos\phi
\]

代码：

```python
phi_deg = 90.0
phi = np.deg2rad(phi_deg)

vr = u * np.sin(phi) + v * np.cos(phi)
```

需要特别注意：

> 数学角度通常以正东方向为零并逆时针增加，而气象方位角通常以正北方向为零并顺时针增加。

使用时必须确认角度定义。

---

## 10. 下采样矢量，避免箭头过密

垂直剖面的网格通常比较密。如果每个网格点都画箭头，图会非常拥挤。

推荐对水平和垂直方向分别下采样。

例如：

```python
x_step = 3
z_step = 2

q = ax.quiver(
    distance[::x_step],
    height[::z_step],
    vr[::z_step, ::x_step],
    (w_factor * w)[::z_step, ::x_step],
    angles="uv",
    scale=250,
)
```

选择原则：

- 水平网格密集时，增大 `x_step`；
- 垂直层数较多时，增大 `z_step`；
- 保证箭头之间有足够间距；
- 重点区域可以使用更密的采样。

---

## 11. 弱风区域的处理

在风速非常小的区域，矢量方向容易受到噪声影响。

可以设置风速阈值，将弱风区域隐藏。

例如：

```python
speed_threshold = 0.5

mask = np.hypot(vr, w_factor * w) < speed_threshold

vr_plot = np.ma.masked_where(mask, vr)
w_plot = np.ma.masked_where(mask, w_factor * w)

ax.quiver(
    distance,
    height,
    vr_plot,
    w_plot,
    angles="uv",
    scale=250,
)
```

这样可以避免在近乎静风区域出现方向随机的小箭头。

---

## 12. 异常值与极端值处理

少量极端风速可能会影响所有箭头的缩放，使正常区域的箭头过短。

可以使用分位数确定绘图尺度。

例如：

```python
vector_magnitude = np.hypot(vr, w_factor * w)

reference_speed = np.nanpercentile(
    vector_magnitude,
    95,
)
```

也可以对用于绘图的风速做裁剪：

```python
limit = np.nanpercentile(
    vector_magnitude,
    99,
)

factor = np.minimum(
    1.0,
    limit / np.maximum(vector_magnitude, 1e-6),
)

vr_plot = vr * factor
w_plot = w_factor * w * factor
```

这样可以降低局地极端值对整体箭头尺度的影响。

需要注意：

> 若进行了裁剪，应在图注或方法说明中注明。

---

## 13. 参考箭头应该如何标注

由于水平风和垂直风使用了不同的比例，普通的单一参考箭头不能完整表示两个分量。

比较清晰的写法是：

```text
Reference vector: 10 m s⁻¹ horizontal wind; vertical velocity ×20
```

或者在图中分别标注：

```text
Horizontal component: true scale
Vertical component: ×20
```

Matplotlib 示例：

```python
ax.quiverkey(
    q,
    X=0.80,
    Y=1.03,
    U=10,
    label=r"10 m s$^{-1}$ horizontal, $w\times20$",
    labelpos="E",
)
```

需要明确：

- 参考箭头主要对应水平风速；
- 垂直分量已经被人为放大；
- 不应把参考箭头理解为真实二维风速大小。

---

## 14. 不同绘图目的下的推荐方法

### 14.1 重点展示上升和下沉区域

推荐：

- 用 \(w\) 做填色；
- 用水平风或放大后的剖面风作辅助矢量；
- 不依赖箭头长度表达垂直速度强弱。

---

### 14.2 重点展示剖面环流结构

推荐：

- 将 \(w\) 放大 10～50 倍；
- 对矢量适当下采样；
- 必要时对矢量归一化；
- 明确标注放大倍数。

---

### 14.3 重点展示真实气流倾角

这种需求最复杂。

不应简单地只放大 \(w\)，而需要同时考虑：

- 水平距离单位；
- 垂直距离单位；
- 坐标轴纵横比例；
- 图中的垂直夸张；
- 风速分量的真实比例。

如果目标是表示空气质点真实运动轨迹，建议改用流线积分，而不是普通 `quiver` 箭头。

---

### 14.4 重点展示风速大小和方向

推荐：

- 底图表示风速强度；
- 归一化箭头表示方向；
- 或用箭头长度表示水平风速，填色表示垂直速度。

避免让一个箭头同时承担过多信息。

---

## 15. 推荐的默认实现

对于大多数气象垂直剖面，可以从以下配置开始：

```python
w_factor = 20
x_step = 3
z_step = 2

q = ax.quiver(
    distance[::x_step],
    height[::z_step],
    vr[::z_step, ::x_step],
    (w_factor * w)[::z_step, ::x_step],
    angles="uv",
    scale=250,
    width=0.002,
)

ax.quiverkey(
    q,
    X=0.82,
    Y=1.03,
    U=10,
    label=r"10 m s$^{-1}$ horizontal; $w\times20$",
    labelpos="E",
)
```

然后根据实际数据调整：

- 箭头太水平：增大 `w_factor`；
- 箭头太竖直：减小 `w_factor`；
- 箭头太长：增大 `scale`；
- 箭头太短：减小 `scale`；
- 箭头太密：增大 `x_step` 或 `z_step`；
- 极端值影响明显：采用分位数裁剪；
- 只关心流向：对矢量归一化。

---

## 16. 最终建议

在常规气象风场垂直剖面中，最稳妥的方案是：

1. 将水平风投影到剖面方向；
2. 使用 \((V_r,\alpha w)\) 绘制剖面矢量；
3. 将垂直速度放大 10～50 倍；
4. 用 \(w\) 的填色表达上升和下沉强度；
5. 对箭头进行适当下采样；
6. 明确标注垂直速度放大倍数；
7. 不把放大后的箭头倾角解释为真实气流倾角。

核心原则是：

> 垂直速度放大是为了增强可读性，不是为了改变物理数据。图中必须清楚区分真实数值与绘图缩放。
